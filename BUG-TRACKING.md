# Wild Workspace v2.7.0 — тестирование и баг-трекинг

## Проверено в автоматизированном браузерном прогоне

- [x] Первый запуск показывает приветствие и подсказку о демо-данных и сбросе.
- [x] В рабочем пространстве появляются 5 примерных задач, 4 мероприятия и 2 привычки.
- [x] Блоки нового пользователя — только «Учёба» и «Работа».
- [x] На домашней недельной доске есть четыре колонки в порядке: «Выполнено», «Перенести», «Запланировано», «В работе».
- [x] Перетаскивание задачи на «Выполнено» устанавливает статус `done` и запускает анимацию котика.
- [x] Новую привычку можно добавить и изменить её прогресс.
- [x] В статистике есть адаптивные секции завершения по блокам и проектов/направлений.
- [x] Кнопка `+` появляется на узких экранах; верхние кнопки создания скрываются. На широких экранах используются верхние кнопки.
- [x] Сброс удаляет задачи, мероприятия, праздники и привычки, оставляет только два базовых блока и открывает приветствие заново; демо-данные повторно не подставляются.
- [x] В проверенных сценариях не зарегистрировано ошибок JavaScript в консоли.

## Адаптивность

Проверены размеры окна: `320×568`, `360×640`, `390×844`, `720×900`, `768×1024`, `1280×800`, `1984×359`. В этих сценариях `document.documentElement.scrollWidth` не превышал ширину окна. На ширине до 720 px используется плавающая кнопка добавления; от 768 px — обычные кнопки в заголовке.

## Известные ограничения / требуется ручная проверка

- Проверка проведена в автоматизированном Chromium. Реальные устройства с сенсорным вводом и разные браузеры стоит проверить отдельно.
- Облачная очистка и синхронизация Supabase зависят от URL, публичного ключа, правил RLS и сетевого соединения конкретного владельца; это не подтверждается локальным браузерным тестом.
- Файлы-вложения и IndexedDB необходимо проверить на опубликованном HTTPS-сайте реальным фото/документом.
- GitHub Pages не был опубликован автоматически: архив готов к ручной загрузке в корень репозитория.
